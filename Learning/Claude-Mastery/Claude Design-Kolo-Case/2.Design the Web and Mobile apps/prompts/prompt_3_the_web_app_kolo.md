# Prompt 3: The Web App

Start a new Claude Design project using the published **Kolo design system**. Attach `kolo/brand/Kolo_Product_Spec.md`.

```
Context: Use the published Kolo system to design the member web app.

Instruction: Design the web app at 1440 pixels wide as one clickable prototype. Include Overview, Circle, Contributions, Payouts and Goal. Today's Circle Health number leads every page. Add the suggested action, the Pot progress and the explanations from the spec. Show all amounts in naira (₦) with comma separators.

Input: kolo/brand/Kolo_Product_Spec.md and its sample member, Adaeze.

Output: kolo_web with all five pages linked and Adaeze's data filled in.
```

Click through every page and check the sample values against the spec.
