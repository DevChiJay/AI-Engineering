# Prompt 1: Start From Monzo

Create a working folder called `kolo` and copy this kit's `brand` folder into it. Open Claude Design and attach `brand/Kolo_Product_Spec.md`. Use Monzo's public site as a reference for this exercise.

```
Context: I am designing Kolo, a fictional group savings circle app. The product spec describes its screens and example member.

Instruction: Go to https://monzo.com and build me a starting design system from it. Study the layout, type scale, spacing, colour use and how they present money and app screens. Explain which choices you used and which you left out. Keep Kolo's name and product details.

Input: monzo.com and brand/Kolo_Product_Spec.md.

Output: Kolo v0 with sample components (score card, Pot progress, member row, payout timeline, primary button) and a short explanation of the reference choices.
```

Review v0 before continuing. If the site capture fails, attach three screenshots of Monzo instead. Publish the revised Kolo system after prompt 2.
