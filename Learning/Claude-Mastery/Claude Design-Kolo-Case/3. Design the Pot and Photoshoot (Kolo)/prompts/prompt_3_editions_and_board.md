# Prompt 3: Editions and the Product Board

Continue in the same Design project.

```
Context: The reviewed Kolo Pot model is ready for edition concepts and a product board.

Instruction: Design three named editions of the Kolo Pot, each with a reason to exist (for example a family circle, a workplace circle and a wedding or celebration circle). Make one product board with the editions, an exploded view of the light ring and tap sensor, packaging and key specs. Add a reference page showing the Pot from three angles on plain ivory with no text.

Input: kolo_pot_3d and kolo_pot_spec.

Output: kolo_product_board and the reference page exported as kolo_reference.png.
```

Save `kolo_reference.png` into `kolo/kolo_assets/` before the photo shoot.
