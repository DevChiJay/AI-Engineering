# Prompt 1: The Spec Sheet

Finish Kolo 02 first (web and mobile). Start a new Claude Design project using the published **Kolo design system**. Attach `kolo/brand/Kolo_Product_Spec.md` from the earlier project.

Kolo is an app, so this project adds a physical companion: the **Kolo Pot**, a screenless tabletop savings pot that sits in the middle of a circle's table. A ring of light fills teal as members pay in and stays saffron for what is still due. Members tap a phone or a keepsake token on top to mark a contribution. It is a concept object only. No real money, coins or payments pass through it.

```

Instruction: Make a one-page Kolo Pot spec with front, side and top views. Include dimensions in millimetres, weight, materials, electronics (light ring, tap sensor, wireless), battery target, charging and three colourways drawn from the Kolo palette. Keep the Pot screenless and give it an original shape, with a monoline coin-ring detail echoing the kolo wordmark. Every number is a first estimate, so flag the five I should check first.

Input: brand/Kolo_Product_Spec.md from the earlier project.

Output: kolo_pot_spec with labelled dimensions and estimates.
```

Review the five flags and change any estimates you disagree with before prompt 2. This approval is a design review, not a manufacturing validation.
